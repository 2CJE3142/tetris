# tetris

## 概要
このテトリスゲームはHTML・CSS・JavaScriptで作成されたシンプルなゲーム。  
フィールドは横10マス・縦20マスで7種類のミノがランダムに落ちてきます。  
ミノは左右矢印キーで移動、上矢印キーで回転し、下矢印キーで加速落下が可能です。  
20マス目を超えてミノが積み上がるとゲームオーバーとなります。  
「リセット」ボタンでゲームを初期状態に戻せます。

## 主な機能とキー操作

- ミノ操作
  - 左矢印キー：左移動
  - 右矢印キー：右移動
  - 上矢印キー：ミノ回転（90度）
  - 下矢印キー：ミノを速く落とす
- ミノはランダムに生成され、1段ずつ自動で落下
- ラインがすべて埋まるとその行を消去し、上のブロックを下に移動
- ミノがフィールド上部まで積み上がるとゲームオーバー
- 「リセット」ボタンでゲームを初期化して再スタート可能

---

## 主なJavaScript関数

- `mino_draw()`：現在のミノを描画（色付け）する
- `mino_undraw()`：現在のミノの描画を消す
- `valid_Move(dx, dy, rot)`：移動や回転が可能か判定
- `mino_move(dx, dy)`：ミノを指定方向に動かす（移動不可なら固定処理）
- `mino_rotate()`：ミノを90度回転させる
- `mino_freeze()`：ミノをフィールドに固定し、ライン消去をチェック
- `clear_Lines()`：埋まった行を消して、上の行を下にずらす
- `mino_spawn()`：新しいミノをランダムに生成し出現させる
- `game_Loop()`：一定間隔でミノを1段下に動かすメインループ
- `reset_Game()`：ゲームを初期化しリスタートする
